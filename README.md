### ⚡ [CodeHarness — Autonomous AI Coding Framework](https://github.com/SoubhagyaJain/CodeHarness)
`CrewAI` • `Python` • `Streamlit` • `Sandboxing` • `HITL`

> **Enterprise-Grade Agent Orchestration:** Built a strict, human-in-the-loop (HITL) framework for autonomous agents using CrewAI.
- **Cognitive Architecture:** Separated execution logic from LLM reasoning using specialized agent roles (*Explorer*, *Coder*, *Tester*).
- **Dual-Execution Sandbox:** Engineered isolated validation layers to test agent-generated code safely before deployment.
- **Real-Time Observability:** Designed an interactive audit console for real-time monitoring of agent reasoning loops and token costs.

</td>
</tr>
<tr>
<td>

### 🏗️ [Vector Steel AI — Zero-Hallucination Estimation Pipeline](https://github.com/SoubhagyaJain/Vector-steel)
`LangGraph` • `Gemini Vision` • `FastAPI` • `React` • `SSE`

> **Deterministic Multi-Agent System (MAS):** Automated structural steel estimation by completely isolating LLM vision from financial math.
- **0% Hallucination Architecture:** LangGraph-powered orchestration uses Gemini strictly for OCR & visual extraction, while a deterministic Python engine computes all pricing & formulas.
- **Adversarial Auditing:** Dedicated *Risk Agent* audits payloads and halts the pipeline immediately upon detecting anomalies or missing tolerances.
- **Streaming UX:** Delivered Server-Sent Events (SSE) to a React/Tailwind frontend, achieving a **91% reduction in perceived latency**.

</td>
</tr>
<tr>
<td>

### 🏢 [Company Policy RAG — Verifiable Legal QA System](https://github.com/SoubhagyaJain/Rag-chatbot)
`LlamaIndex` • `BM25 + Dense Hybrid` • `bge-reranker` • `Qdrant` • `Automated Golden Eval`

> **Production-Minded RAG:** High-precision compliance engine designed for enterprise teams requiring strict legal/policy grounding and non-negotiable citation accuracy.
- **Advanced Retrieval:** Dense + BM25 hybrid search pipeline with `bge-reranker-large` score filtering and query rewriting for peak context precision.
- **Strict Faithfulness:** Enforced LlamaIndex grounding protocols guaranteeing **100% of factual output carries verifiable `[Source N]` tags**.
- **Continuous Evaluation:** Automated golden-set testing framework tracking Context Precision, Context Recall, and Answer Relevancy over time.

</td>
</tr>

- **Model Orchestration:** Automated multi-model benchmarking harness to continuously evaluate, select, and promote the best-performing model.
- **Explainable AI (XAI):** Integrated custom interpretability layers providing security analysts with exact feature-attribution for flagged anomalies.
